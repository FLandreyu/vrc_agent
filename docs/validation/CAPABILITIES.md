## 安全边界备注

- 全部测试均为人工监督、逐键触发；急停（F8）与租约到期（30s）实测有效。
- 2026-10-13 复核修正（R1–R3）：按钮发送前经控制层授权检查、未释放前拒绝新脉冲、释放失败单独记录；证据统计已按 R4 更正（详见 TASKS.md 第 8、10 节）。
- 急停对 Grab 类按钮只发送 0 值（`inputs_released count` 证明输入通道归零）；游戏侧抓取状态不因 0 值解放（Grab 保持语义，见抓取行），急停不发送 DropRight 以避免抛掷副作用。
- 无客户端 ACK 保证：以上"SUPPORTED"均基于人工目视观察，UDP 丢包或客户端异常下的行为未覆盖。
