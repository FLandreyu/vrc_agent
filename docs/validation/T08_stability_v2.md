## 2. 指标与区域决策

现场事实支持“不能零容差”和“大的视角移动明显”，**不支持仅凭 1% 全图阈值就证明安全**。v2 对每个非遮罩像素全量计算 `Δ=max(|ΔR|,|ΔG|,|ΔB|)`，Δ>2 才计为变化；alpha 不参与。没有采样或降分辨率。

同时满足以下要求才 stable=true：

| 检查 | 新策略值 | 意义与限界 |
| --- | --- | --- |
| 黑帧 | 任一帧保留区域全部 RGB ≤8 则拒绝 | 与 v1 一致；9 不是黑，不能据此证明可见或语义正确 |
| 全局 | 变化像素占保留像素 ≤10000 ppm，即 1% | 静止记录 ≤0.56%、移动 ≥61.6% 是选择的输入；不能把不同采样、参考帧、遮罩口径的数字当作该阈值已现场验证 |
| 局部 | 32×32 网格及 x/y 各偏移16像素的四组重叠网格，每格变化像素 ≤15 | 拒绝集中变化；完整 4×4 高对比物体即使跨单一网格边界仍可被另一组捕获。不是所有形状的小目标检测器 |
| 导航证据 | 原推理中目标、forward_clearance、recovery_clearance 的 bbox 向外扩32像素并裁剪到画面，区域内变化像素必须为0 | 能拒绝保护区内单个 Δ>2 像素；不能识别模型没报告的通路或目标，也不能排除 Δ≤2 的真实变化 |

所有判据数值写入新 JSON，并由算法实际读取。全局已拒绝时不再计算局部/保护区计数，报告明确写 null（未计算），不伪装成零。全局/局部用整数计数与整数乘法，无浮点比例边界误差。

区域策略：仅将现场指出的右上 UI 矩形 `[1664,0,1856,512)` 作为**待复验的候选排除区**，约占全帧3.16%；尚不能证明不同姿态下始终不包含世界内容。取消没有正面麦克风证据的旧左下遮罩；**不排除中部镜中角色/粒子区域**。任何源场景实体 bbox 与排除区相交仍报 MASKED_SCENE_EVIDENCE，不因 UI 遮罩而放宽。

取舍：右上 UI 区域内变化被忽略，其他 UI/粒子仍可能触发局部或证据保护而拒绝。镜中动画若集中或处于导航证据区，v2 仍拒绝，G3 等任务可能无法完成。没有证据证明这些反射可与真正进入画面的角色安全区分，不能把它们全遮掉。也不能为让 G1/G3 的大 bbox 通过而绕过 MASKED_SCENE_EVIDENCE。本候选解决渲染舍入抖动，并提供保守的多层防护；**尚不证明它能通过全部五组真实静止姿态或达到16/20**。若现场仍持续拒绝，需要新的语义/区域设计证据，不能临时扩大阈值。

剩余反例边界：导航保护区之外、每个重叠格不超过15个变化像素且全局不超1%的变化仍可能通过；任意位置 Δ≤2 的变化也可能通过。合成测试明确保留保护区外单像素可通过的断言，不声称“所有小物体都不会漏”。画外移动、透明或低对比物体、模型高置信幻觉、捕获源冻结、UI 遮罩内变化和离散检查间变化，均未被证明安全。

## 3. 预热、锚定与时序

每次调用模型前（初始、动作后和不稳定重推理都包括）：采集第一帧后，每隔至少100ms再采一帧并比较相邻帧；连续两对 stable 才取最后一帧作推理参考。至少丢弃前两帧；最多8帧，没有连续两对则 WARMUP_UNSTABLE、零模型调用并暂停。失败对清空连续计数；权限丢失立即退出，不自动重获焦点或重新 ARM。预热时尚无模型实体，所以只检查黑帧/全局/局部，不能声称预热已经检查了导航区域。

推理返回和规划前检查始终比较**该次推理使用的固定原始参考帧**，不与上一检查帧链式滚动。相邻帧每次漂移1–2级、累计到3级时可触发拒绝；在参考下累计仍不超过容差的变化仍是上述剩余限界。每个动作完成后重新预热和推理，不跨动作沿用旧场景。

比较在线程中进行，保留原1000ms计算截止期和30ms级授权轮询，不放宽1500ms观测时效。采用分块16位通道槽的整数并行运算，避免逐像素 Python 循环拖慢授权检查；保护位防跨槽借位。以标量差值为独立 oracle，对256×256通道值组合、多个阈值和三通道变化做穷举回归。无新依赖、无 native 注入、无外部程序。

预热和比较都消耗原30秒任务/租约预算，不能续租。因此可用动作数可能进一步减少；实际耗时需要现场重新测量。线程执行与 Windows 调度不是硬实时30ms承诺；独立控制进程保障不变。

## 4. 证据与汇总

v2 proof 使用 `stable`，不再用 v1 `equal` 冒充逐字节相等。保留完整帧和归一化 RGB 摘要；新增 changed_pixels、retained_pixels、max_tile_changed、protected_changed、protected_rectangles。schema=3 与 stable-inference-v2 必须配对，摘要必须匹配新文件；旧 v1 验证仍要求真实 RGB 摘要相等。

汇总从计数重算 v2 判定，从源实体框重算保护区域；同时校验 warmup_checks / warmup_references 的连续对、时间间隔、帧 ID/摘要接续、session/epoch 与推理来源关系。预热失败或在模型调用前退出时，允许没有 source，但不能伪造已完成推理的来源链。坏证据整份 invalid_files，T10 的 usage/hourly 不改口径。

报告仅支持内部一致性复验；不保存原始像素，计数和哈希不是签名，不能从报告独立证明当时的实际图像。真实实机 usage/hourly 仍待现场产生。
