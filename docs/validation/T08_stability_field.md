# T08 稳定性判据现场标定（2026-10-16，现场会话）

用户在场配合；**未改产品代码/测试/配置/阈值；未启动 live、未 ARM、未发送代理输入、未付费调用**。探针只读取窗口像素并在内存中统计；诊断 PNG 与 JSON 仅存本地 `.runtime/`（不入库、不替代任何验收）。本记录是现场观测证据与判据设计输入，**不是设计批准**。

## 0. 结论摘要

1. **现候选判据 `exact_rgb_outside_mask`（遮罩外任一像素 RGB 有差异即拒绝）在一次真实静止保持中不可能通过**：静止视角下相邻帧仍有约 **60.0% 像素差恰为 ±1、仅 36.0% 完全相等**（±2 以内 99.6%；>2 为 0.37%）。逐像素零容差要求无法在真实渲染输出上成立 → **判据需要修订（新版本 + 新摘要），候选继续 REQUIRES_FIELD_CALIBRATION 并保持 live 拒绝**。
2. **真实"画面变化"的信号极强且可分**：视角移动/前进时 **61.6%–93.4% 像素变化（>2 口径）**，静止姿态为 **≤0.56%**，两者相差 **100 倍以上** → "变化面积占比"型判据有宽阔的阈值空间（例如 1%–30% 区间任选都远高于静止噪声、远低于真实移动）。
3. **持续动画区域 = 客户端 UI 与镜中角色**：右上头像预览面板（含 F4/F5 快捷键图标列）在 60 秒 23/23 对帧中持续变化（Δmax 222）；中部镜面内角色/粒子簇（23/23，Δmax 135–246）；左上提示图标低频变化。**世界实体（浣熊/广告牌/镜框/地板）60 秒完全静止**（>8 变化为零）。
4. **原遮罩（左下 86×144）在静止期无任何活动**（与"仅界面元素"假设一致）；但 **V 键开/关麦在两轮尝试中未产生可观测的像素变化**（无视觉反馈或时机错过，归因不明）——遮罩充分性仍未证实。
5. **方法学教训（重要）**：窗口刚获得焦点后的首帧可能是过渡/未稳定画面。第一轮曾把"参考帧取在过渡瞬间"误读为"场景持续大变化"，经逐帧对比（vs_prev）与全量直方图纠正。**任何标定/复核取参考帧前必须丢弃预热帧**（连续 ≥2 帧稳定后再作参考）。

## 1. 环境与方法

- VRChat 客户端 2026.3.3p2；VRChat Home 私密实例；2160×1440；与冻结世界清单一致。
- 采集：产品 `live_capture`（`window_match=exact`、`UnityWndClass`、无遮挡、DPI per_monitor_v2）；比较与遮罩逻辑直接复用产品 `live_navigation/stability.py` 的 `compare` / `masked_rgb`。
- 统计口径：全量 census（逐像素精确）用于两帧对；长期序列用 stride=3 抽样（345,600 点/对，标注"抽样"）；分块 64×64。
- 时间线（本地 UTC+8）：18:33 预检（失败原因=用户切回编辑器致遮挡，属操作预期）；18:34–18:35 首轮静止序列（参考帧过渡问题，见 §5）；18:37 差异分布（8 帧）；18:40 两帧 census + 热图；18:44 60 秒动态图（24 帧/23 对）；18:47 动作序列（22 帧/21 对，含 35 秒遮挡间隙与用户手动按键）。
- 探针脚本（本地一次性，`.runtime/tmp/`）：`t08_mask_calibration.py`、`t08_stability_probe2.py`、`t08_diff_visual.py`、`t08_dynamic_map.py`。

- 每对帧 gt2 ≤ **0.466%**、gt8 ≤ 0.311%、gt16 ≤ 0.226%（全序列稳定）。
- 持续变化块（frames_touched 21–23/23）：
  - **右上客户端 UI：x≈1664–1856、y≈0–512**（头像预览面板 + F4/F5 图标列），Δmax 222，每对帧都动；
  - **中部镜面内角色/粒子簇：x≈1280±、y≈640±**（含约 (1184–1344, 608–896) 区域），Δmax 135–246，每对帧都动。
- 低频变化块：左上提示图标（x≈128–320、y≈0–128）；左下偏中地板点缀（x≈512–640、y≈1069–1200）；底部小点（x≈600–768、y≈1344–1440）。
- **原遮罩区域（x<86、y≥1296）在 60 秒内无 Δ>2 活动**；底部近地板条带（y≥1280、x≥86）在全部对帧（含运动帧）中无 Δ>8 采样。

**分离度**：真实画面变化（≥61.6% >2）对静止（≤0.56% >2）≈ **110 倍以上**；运动帧的 >16 占比也达 18.6%–71.4%（静止 ≤0.36%）。

## 5. 首轮误读与纠正（方法学记录）

首轮（18:35）与差异分布轮（18:37）的"95%+ 像素大变化"源于**参考帧取在窗口刚获得焦点、视角未稳定的过渡瞬间**：相邻帧对（vs_prev）其实已呈现 §2 的 ±1 抖动 + 局部动画特征（60% 为 ±1），与参考帧的对比才出现 28% >64 的"位移型"分布。纠正后所有结论以相邻帧对与全量 census 为准。**预热帧必须丢弃**。

## 6. 对判据修订的输入（供实现者提案、复核者对抗）

- 逐像素容差路线：即使放宽到 Δ≤2，仍被 0.37%（静止）击穿 → 单纯"全像素 ≤T"不可行；需配合"超限面积占比"或遮罩覆盖 UI。
- 面积容忍路线：静止 gt2 峰值 0.47% 与真实移动 61%+ 之间可选阈值区间约 **1%–30%**，余量 ≥100 倍；须论证慢速渐变、小物体进入、远端细微运动等反例不被放过（复核者职责）。
- 遮罩/区域策略：右上 UI（x≈1664–1856、y≈0–512）与中部镜簇（x≈1184–1344、y≈608–896）若入遮罩，合计约 8% 帧面积；必须论证"遮罩不遮挡导航目标与证据区"（既有 `MASKED_SCENE_EVIDENCE` 检查语义不变）；世界粒子（单像素 Δ 可达 246、面积 ≤0.35%）只能靠面积容忍，不能靠逐像素容差。
- 原遮罩假设"左下 86×144 是麦克风/界面区"未获正面证据（V 键无观测效应）；修订时一并复核。
