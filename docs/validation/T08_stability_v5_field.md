- **比较器性能**：228.8 / 372.7 / 457.2 ms（min/mean/max），在运行时 1000 ms 稳定性预算内（余量 ≈2.2×）。
- **G5 参考候选**：模型框 0.84×0.47、**与遮罩零相交**，且满足现有 `lower_half`（0.6/0.25/0.3）判据 → **仅替换参考图，判据不变**。
