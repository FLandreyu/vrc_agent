## 4. 恢复允许区域（用户确认 2026-10-14）

恢复 = 卡住时向左/向右 200ms 短侧移（约半米）后重新观察，最多两轮。用户核对确认的清单：

| 区域          | 侧移判断                                                            |
| ------------- | ------------------------------------------------------------------- |
| G1 广告牌前   | 开阔，左右侧移安全                                                  |
| G2 浣熊前     | 开阔、安全；不要贴着墙平移（会顶墙）                                |
| G3 镜像面板前 | 开阔、安全；靠近时注意小桩（Mirror Settings）与灯笼                 |
| G4 茶几沙发区 | 茶几与沙发之间、圆凳旁不要侧移（会卡住）                            |
| G5 水池区     | 池边不要侧移（会踩进水）；大石块、石柱、发光圆凳旁不要侧移          |
| 总原则        | 开阔木地板 = 可侧移；贴着任何物体（墙/家具/水池/石头/台阶）= 不侧移 |
